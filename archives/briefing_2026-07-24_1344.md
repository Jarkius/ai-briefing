## 🎯 Prompt Engineering Tips

**Dynamic Context Engineering for Multi-Step AI Agents**
Instead of overloading an AI model's context window with an entire codebase or lengthy manual, dynamic context engineering filters and injects only the relevant state, API specs, and constraints needed for the immediate micro-task. For example, before an agent edits a database query, the system dynamically provides only the active database schema and relevant unit test constraints rather than the entire file repository.
**Key takeaway:** Use dynamic context engineering when orchestrating complex, multi-step agent workflows to reduce hallucinations and keep outputs strictly focused.
